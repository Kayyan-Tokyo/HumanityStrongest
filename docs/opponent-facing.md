# 対戦相手を向く共通ルール

## 原因

以前はidle画像が陣営、歩行シートが移動方向、攻撃シートが別の向き情報で反転を決めていました。このため後退すると背を向け、状態が切り替わると反転が戻っていました。

## 実装

`resolveFacing(character, opponent, previous)` を全キャラ・全状態で使用します。実際に描画する足元のX位置を比較し、相手が右なら+1、左なら-1。同じXなら直前の向きを保持します。初回の同座標だけは共通の既定値+1です。

直前の向きはCanvasごとのWeakMapに保存します。再生時刻が巻き戻ったときは新しい演出として履歴をリセットします。状態切り替えや速度変更ではリセットしません。移動方向は歩行の判定には使いますが、向きには使いません。

素材は全画像が元から右向きであることを確認し、`SPRITES.*.sourceFacing=1` を設定しました。将来は左向き素材なら-1、状態ごとに素材の向きが違えばクリップのsourceFacingで上書きできます。素材属性と共通の相対向きを比較して水平反転するため、キャラ別の向き分岐を追加する必要はありません。

idle/walk/attack/damage/victory/defeatedで同じ反転計算を使います。攻撃・被弾・敗北の傾きと、攻撃のヒット位置も同じ向きを参照します。槍・張り手のヒット位置は攻撃クリップのhitOffsetに移しました。反転は足元の支点を中心に行い、座標・描画サイズ・画像そのものは変更していません。
