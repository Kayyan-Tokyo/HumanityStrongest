# 物語用の状態管理と改善前後の比較

既存の決まり手選択・キャラクター設定・テンプレートを残し、js/story.js内に状態検証と動作列の組み立てを拡張しました。勝敗計算・試合進行・UIは変更していません。

## 記録する状態

| 項目 | 値 |
| --- | --- |
| 距離 | far（打撃が届かない）/ near（打撃が届く）/ grapple（つかんでいる） |
| 各人物の姿勢 | standing（立つ）/ unbalanced（崩れる）/ ground（地面） |
| つかむ手 | なし / 腕 / 胴 |
| 寝技の上下 | 上にいる人物、または未使用 |
| 決着 | 未決着、または確定した勝者 |

ダメージや命中率、行動の成否は計算しません。文章の前提条件だけを扱い、物語の役割winner/loserは保存済みの勝敗に対応します。

## 動作の条件

| 動作 | 前提と遷移 |
| --- | --- |
| 打撃・蹴り | 近距離、立っている、両者のつかみが解除済み |
| 組み付き | 近距離から手を伸ばしてつかむ。手を捕られていれば先に解除 |
| 体勢の回復 | 崩れた姿勢から足を踏み直して立て直す。地面からの無説明な起立には使えない |
| 投げ | 先に組み付き、敗者の体勢を崩してから地面へ |
| 膝蹴り | 近距離または組み付き、両者は地面にいない、敗者が踏み込む/引かれて低くなる |
| 引き込み・タックル | 近づく/つかむ動作から両者の姿勢を地面へ移す |
| 絞め技 | 寝技で上を取る。下なら先にスイープ |
| 関節技 | 両者が寝技に入り、腕を取り直して決着 |
| KO後 | 以降の行動を拒否。地面から無説明に立つ動作も拒否 |

「打撃から組み付いて押し倒す」などの一連の決まり手は、近距離で手が自由という前提を持つ複合動作です。その中の接近・組み付き・転倒も本文に含めます。投げは必ず先行する組み付きと崩れを要求します。

advance()は前提を検査してから状態と文章を一緒に記録します。validateScene()で同じ動作列を最初から再生し、前後の状態と最後の勝者が正しいことを確認します。不正な候補は全文を破棄し、同じ決まり手の別候補を最初から組み立てます。新たな乱数は使いません。

各ラウンドの最終的な文章と状態列はresult.storyに一度だけ保存されます。再表示時には生成しません。状態・動作のキーは画面には表示しません。

## 戦国時代の武士 VS タイのムエタイ選手

勝者：タイのムエタイ選手／決まり手：膝蹴りによるKO

### 改善前

「戦国時代の武士」と「タイのムエタイ選手」が激突。武士が体を横へさばき、ムエタイ選手の腕をつかんだ！ムエタイ選手は足を開いて踏ん張り、押し込まれるのをこらえた。

ムエタイ選手は武士の腕を内側から押し上げた。足を踏ん張り、武士の上体を引き寄せた。武士は押し返そうと、肩を下げて身を乗り出す。

ムエタイ選手の膝蹴りが低くなった武士の上体に命中し、KOを奪った！武士に立て直す間を与えず勝利！

### 改善後

「戦国時代の武士」と「タイのムエタイ選手」が間合いを詰める。武士が体を横へさばき、ムエタイ選手の腕をつかんだ！ムエタイ選手はつかまれた腕を引き、倒れまいと踏ん張った。

ムエタイ選手は武士の手を振りほどき、半歩離れた。踏み込み、武士の上体を引き寄せた。武士は押し返そうと、肩を下げて身を乗り出す。

ムエタイ選手の膝蹴りが低くなった武士の上体に命中！武士はその場に倒れた！ムエタイ選手のKO勝利！

## ヘビー級プロボクサー VS 柔道重量級選手

勝者：柔道重量級選手／決まり手：大外刈りからの押さえ込み

### 改善前

「ヘビー級プロボクサー」と「柔道重量級選手」が激突。ボクサーがジャブを伸ばし、距離を保った！柔道家は腕で顔を守り、一歩ずつ近づく機会をうかがった。

柔道家はボクサーの腕の内側へ踏み込んだ。ボクサーの腕をつかみ、ぐっと引き寄せた。ボクサーは投げをこらえようと踏ん張り、後ろ足へ体重を乗せる。

柔道家はその足を大外刈りで払い、倒れたボクサーを押さえ込んだ！抵抗を振り切り、勝利をつかんだ！

### 改善後

「ヘビー級プロボクサー」と「柔道重量級選手」が間合いを詰める。ボクサーがジャブを伸ばし、距離を保った！その一撃が柔道家をよろめかせた。柔道家は倒れまいと足を踏ん張った。

柔道家は足を踏み直し、体勢を立て直した。懐へ入り、ボクサーの腕をつかんで引き寄せた。ボクサーは投げをこらえようと踏ん張り、後ろ足へ体重を乗せる。

柔道家はその足を大外刈りで払い、ボクサーを倒して押さえ込んだ！抵抗を振り切り、勝利をつかんだ！

## 総合格闘家（MMA） VS ブラジリアン柔術選手

勝者：ブラジリアン柔術選手／決まり手：スイープからの絞め技

### 改善前

「総合格闘家（MMA）」と「ブラジリアン柔術選手」が激突。総合格闘家がパンチでけん制し、低くタックルを仕掛けた！柔術選手は腰を引き、両腕で肩を押さえてこらえた。

柔術選手は総合格闘家の腕を取り、腰を落として座り込んだ。足をからめて総合格闘家を引き込み、下から腰を浮かせた。総合格闘家は上に残ろうと手をつくが、体が横へ傾く。

柔術選手はスイープで上下を返し、絞め技で総合格闘家を降参させた！番狂わせの勝利だ！

### 改善後

「総合格闘家（MMA）」と「ブラジリアン柔術選手」が間合いを詰める。総合格闘家がパンチからタックルで胴に組み付いた！柔術選手は腰を引き、両腕で肩を押さえてこらえた。

柔術選手は総合格闘家の手を振りほどき、半歩離れた。柔術選手は踏み込んで総合格闘家の腕を取った。座って総合格闘家を地面へ引き込み、下から腰を浮かせた。総合格闘家は上に残ろうと手をつくが、体が横へ傾く。

柔術選手はスイープで上下を返し、総合格闘家の上に回った。柔術選手は首へ腕を回し、絞め技で総合格闘家を降参させた！番狂わせの勝利だ！
