# 格闘ストーリー品質改善・第3弾：30件の読み直し記録

`node tests/story-examples.cjs` で再現できる、重点5対戦×両勝者×3展開の30件です。各対戦・勝者に最低2種類の動作列を含めています。同じ確定結果での改善前後は [story-state.md](story-state.md) に記録しています。

確認した点：

- 武士対ムエタイ：つかまれた腕を振りほどいてから上体を引く筋と、二歩離れて再接近を待つ筋を確認。膝の届く距離・低い姿勢→命中→転倒→ムエタイ選手のKO勝利までつながります。
- ボクサー対柔道家：手を放さずパンチを使うことがなく、離れた場合は踏み込みや追う動作を挟みます。柔道家の勝利は腕を取って体勢を崩し、大外刈りで倒して押さえ込む順です。
- オイルレスラー対スパルタ兵：組み付いた手をほどいてから組み直し、片足に乗った重心へ足掛け。逆の勝者では短い打撃から組み付き、前へ来る力を使って投げます。
- MMA対柔術：タックルから地面に移った後は、床に手をつく抵抗と関節技で完結。柔術の下からの絞め技は、必ずスイープで上を取ってから行います。倒れた人物が立った状態に戻る描写はありません。
- 一般人対プロ：一般人は必死に顔をかばう、押されて下がる、体当たりを合わせる動きに限定。新たな専門技を加えていません。
- 読み直しで「二歩下がって追わせる」を重ねた例や「踏み込む」の重複を削除。手をほどいて近い間合いから組み直す場合は、踏み込みも本文へ反映しました。
- 勝者が先に打撃を受ける展開では、よろめく→足を踏み直して体勢を戻す→反撃、を確認。状態上も崩れたまま攻撃していません。
- KOは命中・敗者の転倒・勝者名付きのKO勝利で締め、その後の行動はありません。短縮名を含む主語と決まり手を全30件で確認しました。

自動検証だけで文章品質を判断せず、以下の本文を読み直して接続と動作を確認しています。勝率や能力・試合ルールは変更していません。以下は演出用の物語です。
