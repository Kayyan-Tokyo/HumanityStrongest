# リザルトストーリー品質改善・第2弾の読み直し記録

`node tests/story-examples.cjs` で再現できる20件です。実際の判定関数に固定乱数を渡し、9組の両勝者時18件と、MMAの関節技2件を生成して読み直しました。

確認した点：

- 米兵対剣闘士は大戦期・現代の米兵それぞれで両勝者を確認。勝者のパンチ命中→敗者が顔をかばって後ずさる→勝者が組み付いて地面へ押し倒し制圧、が本文と決まり手で一致しています。
- ボクサー対柔道家は、組み付きを離してジャブ・ストレート・フックへつなぐ場合と、パンチの内側へ入り重心が乗った足を大外刈りする場合を確認。
- ムエタイ対MMAは、タックルをこらえて膝蹴りが命中する場合と、蹴りの戻りに踏み込んで打撃またはタックル・寝技・関節技へつなぐ場合を確認。
- オイルレスラー対スパルタ兵は胴を抱えて足掛けする場合と、短い打撃から組み直して投げる場合を確認。
- 一般人の勝利は体当たり・とっさのパンチ・押し返し。専門的な投げや関節技を追加していません。負ける場合にも不器用な攻撃や腕を上げて守る抵抗を残しました。
- 冒頭に正式名称を置き、以降は短縮名で主語を明示。2種類の米兵、2種類の力士なども同名になりません。直前の文と同じ勝者が続けて動く場合だけ主語を省略しています。
- 読み直しで見つかった「腰を落とす」の反復を削除し、距離を変える文・反撃の文・敗者の抵抗の文を分けました。MMAが上から体を押さえる→敗者が腕を床につく→関節技、の順にして、押さえた腕が突然自由になる描写も避けています。
- 全例で勝者・敗者・決まり手を確認。「逆転」「番狂わせ」は事前勝率50%未満の側が勝った場合だけです。接戦の分類は従来どおりです。

ゲーム本体のキャラクター設定・能力値・勝敗計算・試合ルール・保存処理は変更していません。以下は試合の演出用ストーリーです。
