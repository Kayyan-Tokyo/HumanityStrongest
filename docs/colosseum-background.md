# コロシアム背景の導入準備

## 現在の状態

今回の依頼には背景画像の添付がなく、添付領域には既存のキャラクターCSVのみがありました。リポジトリのスクリーンショットも背景には使用していません。画像ファイルは未導入です。画像が届くまでは既存のダーク背景と中央の暗幕を表示し、存在しない画像へのリクエストは発生しません。

## 画像を追加する方法

1. 提供された元画像を確認し、闘技場の中心の位置・縦横比・容量を調べます。
2. 大きい画像は縦横比を保ち、長辺1600〜2000px程度のWebPに変換します。品質80〜85を出発点に、石壁・照明の見た目を原画像と比較してください。目安は500KB以下ですが、画質を優先し、既に小さい画像の再圧縮や拡大は不要です。元画像の透過がある場合は保持します。
3. `assets/backgrounds/colosseum.webp` に追加します。PNG/JPEGのまま使う場合は設定側の拡張子も合わせます。
4. `index.html` 冒頭の設定を次のように変更します。

   ```css
   --arena-background-image: url('./assets/backgrounds/colosseum.webp');
   --arena-background-position: 50% 50%;
   --arena-background-overlay: rgb(10 9 15 / 72%);
   ```

   URLはHTMLを基準とする相対パスです。`/assets/...` のような先頭スラッシュを使わないため、GitHub Pagesの `/HumanityStrongest/` 配下でも読み込めます。CSSを別ファイルへ移す場合は、そのCSSファイルからの相対パスに直してください。

5. 闘技場の中心が元画像の中央でない場合は、提供画像に合わせて `--arena-background-position` を調整します。文字が読みにくい場合は暗幕の72%を大きくします。画像を差し替える場合は同じファイルを置き換えるか、上記のURLだけを変更します。

## 配置と既存機能

背景の適用範囲は中央の `.battle-arena` です。CPU・あなたの選択カードの背面に、画像と半透明の暗幕を別レイヤーとして描画します。手札・結果・タイトルの背景は既存のデザインを維持します。

`background-size: cover` で領域を覆い、画像の縦横比を保ちます。幅に合わせて周辺が切れる可能性があるため、実画像の受領後に375/390/430pxとPCで中心の位置を調整してください。結果の物語が長くなっても、その領域は背景要素の外にあるため画像のサイズ・中心は変わりません。

背景は通常のページと一緒にスクロールします。`fixed` や `sticky`、独立した背景アニメーションは使いません。既存の衝突時の微振動はそのままです。背景はレイアウト寸法を持たず、クリックを受け取らず、カード・炎・フラッシュの背面にあります。勝率・乱数・カード移動・ストーリーのJavaScriptには変更を加えません。

## 検証と残作業

- `node tests/background.browser.cjs`：375/390/430/1280pxで、画像未設定時に画像リクエストが発生しないこと、手札各3枚・プロフィール・横はみ出し・背景のレイヤー・スクロール追従・結果表示後の背景位置を確認します。`/HumanityStrongest/` 配下の相対URL解決と、一時的なテスト図形での背景設定を確認します。製品に別の背景画像を採用することはありません。
- `WIDTHS=375,390,430,1280 node tests/mobile.browser.cjs`：両先攻、カード移動・燃焼・WIN・連打防止・3ラウンド・保存済み結果を確認します。
- ブラウザのURLへのnavigationに実行環境の制限があるため、ブラウザ検証では実ファイルをインライン化しています。画像受領後に実画像での見え方、最適化後の容量・画質、実際のGitHub Pages配信を最終確認します。現段階ではコロシアム画像そのものの見え方は確認できません。
