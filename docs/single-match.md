# CPU1人に、候補2人から挑む単発対戦

ゲーム開始時に公式30人をシャッフルし、先頭をCPU、続く2人をプレイヤー候補にします。3人のIDは重複しません。CPUは最初から表向きで、上部中央とバトルスロットに同じ1人を表示します。プレイヤーは下部の2枚から1枚をタップすると、配置演出、既存バトル、リザルトまで自動で進みます。

1試合で終了し、リザルトの「次の対戦」で新しい3人を抽選します。選択前の配り直し、先攻後攻の抽選、2勝先取、次ラウンドは廃止しました。バトル中の連打・次の対戦の連打で、判定や配布を重複実行しません。

## 連勝と保存

- 画面上部の固定ヘッダーで「現在の連勝数」「最高連勝数」を常時表示します。
- あなたの勝利で+1、敗北で0、引き分けなら維持します。
- 最高記録のみ `localStorage` の `humanityStrongest.bestWinStreak.v1` に整数文字列で保存します。ページを開き直すと最高記録を復元し、現在の連勝数は0から始まります。
- 同じ保存済み結果は `WeakMap` で一度だけ集計します。表示モードの変更で勝利を加算しません。
- 記録値が不正なら0として開始します。保存拒否や容量超過でも対戦を続け、そのページ内では記録を保持します。保存できない場合は最高記録の補足説明（title属性）を更新します。
- 通常勝利は連勝数と通知を約300msで強調。5・10・20連勝は金色の通知・光・拡大を約750msで表示します。reduced-motion・スキップ・ページ非表示では演出を短縮し、数値は同じように更新します。

現行 `battle.js` は勝利か敗北のみを返します。今回、引き分けの確率や条件は追加していません。将来 `winner:'draw'` を受け取った場合には、連勝を維持し、勝者のいない結果を表示します。どちらかのカードを勝者として燃焼・WIN表示することはありません。

## 変更箇所と維持する処理

- `js/match.js`：CPU1枚/候補2枚の配布、CPUの先決め、1回の選択と判定、1試合終了。`round:1` と `firstSide:'cpu'` は既存の保存済みストーリー形式との接続に用います。
- `js/streak.js`：連勝の集計、最高記録の読み書き、同じ結果の重複集計防止。判定と描画から分離したモジュールです。
- `js/game.js`：1タップからリザルトまでの進行、次の対戦、固定記録表示と連勝演出。
- `index.html`：CPU1枚の中央配置、候補2枚横並び、記録ヘッダー、連勝通知、次の対戦ボタン。

30人の公式データ/能力値、`battle.js` の勝率計算と勝敗判定、通常結果のストーリー生成、能力比較表・勝率表示は維持します。配布方式の変更に伴い、対戦準備の乱数使用数は変わりますが、勝敗用乱数は既存の判定関数で対戦ごとに1回だけ使います。演出と連勝管理は勝敗用乱数を使いません。

カードバトルとドット絵モードを両方維持します。`sprite-registry.js` のIDから、選択した2人の既存素材/代替表示を選びます。登録表、ピクセル描画、8枚の既存スプライト、コロシアム背景は変更していません。1倍/2倍速、途中変更、スキップ、非表示時の終了も従来どおりです。

将来予定の平坦なコロシアム・開始距離10m・武器・現実寄りシミュレーションは今回追加していません。

単体テストで3,000回の配布の重複なし/全30ID出現、両候補の選択、1回の判定と結果保存、集計重複防止、5/10/20達成、最高記録の保存/復元、不正値、保存失敗、引き分け結果への対応を確認します。公式CSVの全項目一致、勝率式、既存ストーリー・状態遷移・描画のテストも実行します。

Chromiumの375/390/430/1280pxで、CPU1枚の中央配置、候補2枚の横並び、長い名前、固定ヘッダー、連打防止、1試合終了と次の対戦、通常/節目の連勝演出、1倍/2倍速/スキップ/ページ非表示、画像IDの入れ替えとフォールバックを確認します。同一乱数入力のカード/ピクセル両モードで、カード・勝率・勝敗・保存ストーリー・乱数呼び出し回数・連勝記録が一致します。

この環境ではブラウザのページ遷移が制限されるため、HTMLと実画像をインライン化します。保存/復元のUIテストは `tests/helpers/browser.cjs` の明示的なStorage互換テスト領域で行い、保存した値から新しい画面を起動して復元を検証します。製品の保存コードは標準のlocalStorage APIです。ネイティブ保存のブラウザ再読み込み、実機Safari、公開GitHub Pages配信は未確認です。

確認用スクリーンショットは任意のフォルダーへ保存できます。
