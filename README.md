# HumanityStrongest
Humanity's Strongest - Browser Card Battle Game

## 起動

`index.html` をブラウザで開くか、GitHub Pagesでリポジトリのルートを公開してください。HTML・CSS・JavaScriptのみで動作し、ビルド、サーバー、外部ライブラリ、APIは不要です。

## 対戦準備の操作

1. 「ゲーム開始」で30人から重複なしに8人を抽選し、プレイヤーとCPUに4枚ずつ配ります。
2. CPU手札は画面上部の横4枚の裏面、プレイヤー手札は下部の2列×2段です。中央にVSを表示します。
3. プレイヤーのカードは名前・年齢・身長・体重のみ表示します。タップ、またはTabでフォーカスしてEnter/Spaceで1枚選択します。同じカードで解除、別のカードで切り替えます。
4. 「このキャラで戦う」で対戦準備画面へ進みます。未選択では進めません。CPUの出場カードは配布時に内部で決まり、この段階では裏向きです。
5. 「バトル開始」でCPUの出場カードを公開します。短い回転演出があり、動きを減らす設定では省略します。勝敗計算や本格的なバトルは未実装です。
6. 公開後の「手札に戻る」では、両者の手札・プレイヤーの選択・CPUの出場者を保持します。再度対戦準備へ進むとCPUカードを裏向きに戻しますが、出場者は変わりません。
7. 手札画面の「配り直す」だけが両者の手札とCPUの出場者を再抽選し、プレイヤーの選択を解除します。前回の人物が再登場することはあります。

CPUの未公開情報を裏面のDOM・ラベル・data属性へ埋め込みません。すべてブラウザ内で処理するゲームのため、開発者ツールによる内部データの調査を防ぐ仕組みではありません。

## 仮キャラクターデータ

`js/characters.js` の `window.CHARACTERS` は既存の30人分の仮データです。名前・年齢・身長・体重・全能力値は動作確認用であり、正式な設定ではありません。

正式データの提供後に各オブジェクトを差し替えてください。`id` は一意、`age` は歳、`height` はcm、`weight` はkg、`stats` はSTR・SPD・END・STK・GRP・SUBの数値です。0〜100という能力値の尺度も暫定です。能力値は画面やアクセシブル名には出力しませんが、手札・出場カードのオブジェクト内に保持し、将来の勝敗計算やリザルトに使用できます。

`js/match.js` は両者の配布とCPU出場カード選択、`js/game.js` は画面遷移・選択・公開を担当します。戻る操作では配布関数を呼びません。

## テスト

開発環境で `node tests/deal.test.cjs` を実行してください。外部テストライブラリは不要です。30人のデータ構造、1000回の8人重複なし抽選、能力値保持、CPUカードの所属、乱数の両端、不正データの拒否、画面切り替え、未選択時の制御、プロフィール表示、能力値非表示、CPU情報の非表示、選択・解除・切り替え、公開と再入場、戻る時の手札・選択・CPU出場者保持、再配布時のリセットを検証します。

このテストは最小DOMによるロジック検証で、実ブラウザのレイアウトやアニメーションの目視確認を代替しません。Node.jsはゲームの実行には不要です。
