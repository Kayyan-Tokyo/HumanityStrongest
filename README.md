# HumanityStrongest
Humanity's Strongest - Browser Card Battle Game

## 動作確認

`index.html` をブラウザで開くか、GitHub Pagesでリポジトリのルートを公開してください。ビルドやサーバー、外部ライブラリ、APIは不要です。

- 「ゲーム開始」で30人から重複なしに4人を抽選します。
- 「配り直す」で再抽選し、選択を解除します。前回と同じ人物が含まれることもあります。
- カードをタップ、またはTabでフォーカスしてEnter/Spaceで選択できます。もう一度押すと解除し、別のカードを押すと選択を切り替えます。対戦はまだ開始しません。
- 900px未満は2列×2段、900px以上は横4枚です。

## 仮キャラクターデータ

`js/characters.js` の `window.CHARACTERS` がデータ本体です。30人の名前・年齢・身長・体重・全能力値はすべて動作確認用の仮データで、正式な設定ではありません。

正式データが提供されたら各オブジェクトを差し替えてください。`id` は一意、`age` は歳、`height` はcm、`weight` はkg、`stats` はSTR・SPD・END・STK・GRP・SUBの数値です。現在の0〜100という能力値の尺度も暫定です。抽選と画面表示は `js/game.js` に分離しています。

## テスト

Node.jsがある開発環境では `node tests/deal.test.cjs` で、30人のデータ構造、画面切り替え、4枚表示、1000回の重複なし抽選、選択・解除・切り替え、再抽選時の選択解除、元データの非破壊を検証できます。Node.jsはゲームの実行には不要です。
